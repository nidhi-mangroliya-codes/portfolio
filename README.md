# Nidhi Mangroliya — React Portfolio

## Run locally
1. Install Node.js if it is not installed.
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed in the terminal.

## Pages
- `/` Home
- `/about` About
- `/skills` Skills
- `/projects` Projects
- `/resume` Resume
- `/contact` Contact

The design follows the supplied reference: warm cream background, orange accents, rounded cards and responsive layouts. The photo area is a placeholder until a profile photo is added.
